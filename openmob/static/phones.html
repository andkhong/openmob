Permission prompts

When the app a task is using asks for a permission ("Allow Kalshi to use your location?"), the agent answers by these settings with no prompt: by default "Only this time" (or the narrowest grant the dialog offers), notifications allowed, location approximate. Never "Allow all the time". Another app's request asks you on the phone. Allowing more (While using the app, Precise) needs your approval on that phone, with its screen lock; tightening is immediate.

Blocked apps

Agents can't open or act in these apps on the phone, in any mode. The phone keeps and enforces this list; what you see here is a copy from its last connection. Built in on every phone and never removable: banking and payments, wallets and crypto, passwords and sign-in codes, and OpenMob itself.

    To unblock an app, open OpenMob on the phone: Settings › Blocked apps. It asks for the phone's screen lock. Nobody can unblock an app from here.

    The request goes to the phone, which adds the block now if it's connected, or when it next connects. Blocking never needs the screen lock.
